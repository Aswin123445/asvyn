# Target Career Roles

## Purpose

This document defines my target career roles and the direction in which I want to develop professionally.

My primary focus is Python backend development, with a growing specialization in Generative AI, LLM-powered applications, RAG systems, and AI agents.

The roles below represent career targets, not claims that I already meet every requirement.

## 1. Python Backend Developer

**Priority:** Primary

### Role Objective
Build reliable backend applications, REST APIs, database integrations, authentication systems, and background-processing workflows using Python.

### Relevant Technologies
- Python
- Django and Django REST Framework
- FastAPI
- PostgreSQL and MySQL
- SQL and ORM
- JWT authentication
- Celery and Redis
- Docker, Nginx, and Gunicorn
- Git and CI/CD

### Development Priorities
- Strengthen Python fundamentals and problem-solving.
- Improve API design, validation, and error handling.
- Deepen SQL, indexing, transactions, and query optimization.
- Practice testing and maintainable architecture.
- Improve deployment and debugging skills.

### Relevant Projects
- CivicEdge
- JobDiary
- RailConnect
- Are We Dating?

## 2. Backend Software Engineer

**Priority:** Primary

### Role Objective
Design, implement, test, and maintain backend services with an emphasis on correctness, reliability, scalability, and maintainability.

### Relevant Areas
- API and service-layer design
- Database modeling and transactions
- Authentication and authorization
- Asynchronous processing
- Caching and concurrency
- Automated testing
- Debugging and observability
- System design

### Development Priorities
- Build stronger system-design fundamentals.
- Document real technical decisions and trade-offs.
- Practice concurrency, caching, and failure handling.
- Add unit, integration, and regression tests to projects.
- Demonstrate solutions to real engineering problems.

## 3. Generative AI Application Developer

**Priority:** Primary specialization

### Role Objective
Build software applications that integrate LLMs with APIs, databases, structured workflows, and external tools.

### Relevant Technologies and Concepts
- LLM APIs, including Groq and OpenAI
- Prompt engineering
- Structured outputs
- Embeddings and semantic search
- Retrieval-Augmented Generation
- Vector databases such as Qdrant
- Streaming responses
- Evaluation and grounding

### Development Priorities
- Build complete AI features rather than isolated API demonstrations.
- Validate model outputs and handle provider failures.
- Evaluate retrieval relevance and answer faithfulness.
- Control latency, token usage, and API costs.
- Build reliable AI features using backend engineering principles.

### Relevant Projects
- JobDiary
- Are We Dating?
- Purushu
- Portfolio AssistNet

## 4. AI Engineer / AI Agent Developer

**Priority:** Longer-term specialization

### Role Objective
Develop AI systems that combine language models, retrieval, tools, state, and controlled multi-step workflows.

### Relevant Learning Areas
- LLM tool and function calling
- Agent workflow orchestration
- RAG and retrieval optimization
- State and memory management
- Structured tool inputs and outputs
- Evaluation and observability
- Error recovery and safety controls

### Development Priorities
- Complete a working semantic search pipeline.
- Implement and evaluate a complete RAG application.
- Learn when a deterministic workflow is preferable to an agent.
- Build tool-calling workflows with validation and controlled permissions.
- Measure reliability instead of judging systems only by successful demonstrations.

### Career Positioning
This is a developing specialization. Practical projects and verified implementations should support future applications for AI engineering and agent development roles.

## Job Selection Criteria

When evaluating a job opportunity, consider:

- Alignment with Python backend or AI application development.
- Opportunity to work on real software systems.
- Technical mentorship and engineering practices.
- Scope for learning databases, architecture, testing, and deployment.
- Compensation, location, working arrangement, and career progression.
- Whether the role's actual responsibilities match the advertised title.

Do not reject or accept an opportunity based on the title alone; evaluate the job description and employment conditions.

## Long-Term Direction

Develop into a strong backend engineer who can design and deploy reliable Python services and build useful AI applications on top of them.

The immediate objective is to strengthen backend engineering fundamentals while building demonstrable LLM and RAG projects. Agentic systems are a specialization to develop through practical implementation and evaluation.
