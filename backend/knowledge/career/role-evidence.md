## 6. Evidence Classification

Classify each claim before using it in a resume, interview, or portfolio response.

- **Implemented:** The feature or capability was built.
- **Verified:** Its behavior has been checked through tests or reproducible evidence.
- **Explored:** The technology or concept was investigated through learning or experiments.
- **Planned:** The feature is intended but has not yet been implemented.
- **Needs confirmation:** Available documentation does not establish the exact implementation or outcome.

A project containing a technology does not, by itself, prove expertise in every aspect of that technology.
